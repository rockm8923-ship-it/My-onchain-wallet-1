# My Onchain — V1

A clean Ethereum/on-chain dashboard built from scratch with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current version

- Responsive dashboard UI
- Connect Wallet button
- MetaMask/EIP-1193 connection attempt
- Demo ETH/USDT/USDC balances
- Demo transaction activity
- Send / Receive / Explorer UI
- No private keys are requested or stored

## Next steps

Replace demo balances/activity with real RPC/indexer data and add a real wallet connection library such as wagmi + viem.
